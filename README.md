# 🏨 Hotel Chain Management System - MySQL 

## 🇺🇸 English

This repository contains the relational architecture and advanced database logic for a comprehensive multi-property hotel chain management system, built with **MySQL**. It is modeled around a fictional hotel chain created to design and implement secure, structured, and reliable data management.

### 🚀 Repository Structure

The project is organized into the following SQL scripts:

1. **`Santiago Uribe - hotelpro.sql`**: Core database schema featuring **25+ normalized tables** along with initial seed data.
2. **`INNER hotelpro.sql`**: Complex queries leveraging **`INNER JOIN`** to connect guests, reservations, rooms, and payments.
3. **`Views And Stored Procedures - hotelpro.sql`**: Database views to streamline reporting and Stored Procedures for business process automation.
4. **`Triggers And Fuctions - hotelpro.sql`**: Database triggers for auditing and data validation, alongside custom user-defined functions.
5. **`Events - hotelpro.sql`**: Scheduled events for automated maintenance and recurring tasks.

### 🛠️ Tech Stack

- **Database Management System:** MySQL
- **SQL Client:** HeidiSQL
- **Database Modeling & Querying:** DDL, DML, DCL, TCL, Triggers, Views, Functions, and Stored Procedures

## 🇪🇸 Español

# 🏨 Sistema de Gestión de Cadena Hotelera - MySQL

Este repositorio contiene la arquitectura relacional y la lógica avanzada de base de datos para un sistema integral de gestión de una cadena hotelera (multi-propiedad), desarrollado en **MySQL**. El proyecto está basado en una cadena de hoteles ficticia creada para diseñar e implementar un manejo de datos seguro, organizado y confiable.

### 🚀 Estructura del Repositorio

El proyecto está organizado en los siguientes scripts SQL:

1. **`Santiago Uribe - hotelpro.sql`**: Esquema principal de la base de datos con **más de 25 tablas** normalizadas e inserción de datos iniciales.
2. **`INNER hotelpro.sql`**: Consultas complejas utilizando **`INNER JOIN`** para relacionar huéspedes, reservas, habitaciones y pagos.
3. **`Views And Stored Procedures - hotelpro.sql`**: Vistas para simplificar reportes y Procedimientos Almacenados (*Stored Procedures*) para la automatización de procesos.
4. **`Triggers And Fuctions - hotelpro.sql`**: Disparadores (*Triggers*) para auditoría y validación de datos, junto con funciones personalizadas.
5. **`Events - hotelpro.sql`**: Eventos programados para mantenimiento automatizado y tareas recurrentes.

### 🛠️ Tecnologías Utilizadas

- **Sistema Gestor de Base de Datos (SGBD):** MySQL
- **Cliente SQL:** HeidiSQL
- **Modelado y Consultas:** DDL, DML, DCL, TCL, Triggers, Vistas, Funciones y Stored Procedures
